# Prowl — Influencer GTM Plan (Micro/Nano Creator Seeding)

**Goal:** 10,000 users via micro/nano influencer seeding.
**ICP:** Job seekers 20–35, tech/white-collar, US + India + global English.
**Product hook for creators:** "Upload your resume → AI finds matching jobs AND the hiring managers → generates a personalized pitch page + AI avatar video." This is inherently demo-able, screen-recordable, reaction-friendly content — perfect for CareerTok formats.

## 4. Influencer Ops Process

### Tracking sheet columns (Google Sheet / Airtable)

`Creator name | Handle | Platform(s) | Follower count (date checked) | Avg views (last 10 posts) | Engagement % | Niche/archetype (recruiter POV / layoff / new-grad / tech / India) | Email/DM channel | Agent? | Status (Not contacted → DM'd → Replied → Negotiating → Contracted → Briefed → Posted → Paid) | Offer rung (L0–L4) | Agreed fee | Affiliate code | UTM link | Post URL | Post date | Views | Likes | Comments | Link clicks | Installs | Signups | Cost per install | Usage rights (none / organic 30d / paid 90d / whitelist) | Rights expiry date | Spark Ads code received? | Contract link | W-9/W-8BEN received | Payment status | Notes / next follow-up date`

### Follow-up cadence

- **Day 0:** DM (short template above)
- **Day 3:** Follow-up in same thread — add 1 new proof point (screenshot of the avatar video feature)
- **Day 7:** Switch channel (DM → email in bio, or comment on latest post)
- **Day 14:** Final "no worries" touch + leave the free Pro code anyway (seeds future organic mentions)
- Then mark Closed–Lost, revisit in 90 days with traction stats ("we've had 6K signups since we last talked")
- **Post-deal:** brief within 48h of signing; content draft check within 7 days (concept-level notes only — don't script them); post goes live; pay within 7 days of posting (fast payment = referrals to other creators)

### Usage-rights ask (standard language for every contract)

> "Brand receives a 30-day license to reshare the content organically on Prowl's owned channels with credit. Brand may purchase: (a) 90-day paid usage rights at +40% of base fee, and/or (b) allowlisting/Spark Ads rights at +75% of base fee for 60 days, exercisable within 14 days of posting based on performance."

This makes rights an *option you buy on winners only* — you never pre-pay usage on content that flops. Also require: FTC/ASCI disclosure (#ad), no copyrighted music on any clip you may boost (Spark Ads + trending audio = licensing liability), and revocable consent IDs logged in the tracking sheet.

### Whitelisting for ads (the scale lever)

1. After 7 days, rank all live posts by installs-per-1K-views.
2. For the top ~20%, exercise the whitelisting option: TikTok → request Spark Ads auth code (60-day); Meta → Partnership Ads via Business Manager access.
3. Run the creator-handle version against your brand-account version; creator-handle ads typically win on CPA.
4. Renew or let expire based on CPA; track expiry dates in the sheet — running ads past the rights window is the #1 legal foot-gun.
5. Feed learnings back: the hooks that win as ads become the brief for the next creator wave.

### Weekly ops rhythm

- **Mon:** pipeline review (10 new creators added to sheet, 10 first-touches sent)
- **Wed:** follow-ups due today + content approvals
- **Fri:** performance pull (views/installs per live post), decide whitelisting exercises, pay invoices
